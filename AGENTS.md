# Repository instructions

## Battlewire web integrations

When working on the Battlewire web integration, read and follow the canonical
[Battlewire web port architecture](../battlewire/docs/web-port-architecture.md).
In isolated worktrees, read `docs/web-port-architecture.md` from the Battlewire
checkout for the current task instead of assuming the sibling path exists.
Keep shared architecture rules in that document; retain engine-specific APIs,
build instructions, and repository conventions in their owning repository.
These integration rules apply to Battlewire work and do not expand the scope of
unrelated upstream changes.
